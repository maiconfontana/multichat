        Recursos

        O que o MultiChat faz hoje.

        🔐 Isolamento por conta

        Cada conta usa seu próprio perfil de navegação: você pode ficar logado em dois WhatsApp, duas contas do Teams, o que precisar — sem uma derrubar a outra.

        🪶 Impacto de memória controlado

        As contas são carregadas sob demanda e suspendidas após um tempo sem uso, devolvendo RAM sem perder o login. O prazo é configurável.

        🔔 Notificações e badges

        Notificações nativas com o nome da conta, contador de mensagens não lidas na barra lateral e na bandeja do sistema, e ícone de tray para não fechar sem querer.

        🖥️ Compartilhamento de tela

        Seletor próprio de telas e janelas, funcional no WhatsApp Web.

        🤖 Assistente contextual

        Em contas do WhatsApp, gera um rascunho a partir das mensagens visíveis e insere no campo de edição — o envio continua sempre sendo seu.

        📴 Interface offline

        Estilos e ícones são empacotados no app, sem depender de CDN para desenhar a interface.

        Compatibilidade por plataforma

        O que é só limitação de assinatura e o que é limitação real.

        Windows

        Aviso do SmartScreen na primeira execução, por falta de certificado de assinatura de código (que é pago). O app funciona normalmente depois de confirmar.

        macOS

        Precisa da liberação manual descrita acima. Aqui não existe atalho gratuito: assinatura e notarização exigem o Apple Developer Program pago.

        Linux

        AppImage e tar.xz, 64 bits. Não há repositório APT ou pacote Flatpak/Snap publicado — distribuição direta pelo GitHub Releases.

        Instalação

        Depois de baixar, instale por cima da versão anterior: as contas e preferências são preservadas.

        Windows

        Baixe MultiChat-<versão>-setup.exe e execute.

        macOS

        Baixe o .dmg correspondente ao seu Mac (arm64 para Apple Silicon),
arraste o MultiChat para Aplicativos e libere em Ajustes → Privacidade e Segurança.

        Linux

        chmod +x MultiChat-<versão>.AppImage
./MultiChat-<versão>.AppImage

        Rodar do código-fonte

        Requer Node.js v24.

        git clone https://github.com/maiconfontana/multichat.git
cd multichat
npm install
npm run start

        O repositório traz npm test (testes unitários), npm run check (validação de sintaxe) e os scripts de build por plataforma. Veja o README para o guia completo.
