          O que a versão atual entrega

          Recursos

          Sem roadmap como promessa. Tudo abaixo está no app publicado hoje — se ainda não existe, não está nesta lista.

          • contasPerfil isolado, não aba separada

            Dois WhatsApp, dois Teams, o que precisar. Cada conta ganha um perfil de navegação próprio, com cookies e armazenamento separados, então um login não derruba o outro. O mensageiro continua sendo o site oficial: o app abre web.whatsapp.com, teams.microsoft.com e companhia — não existe cliente próprio nem servidor intermediário.

          • memóriaHiberna quem está fora de foco

            A conta só carrega quando você abre e, depois de 60 minutos sem uso (padrão), é descarregada da RAM sem perder o login — o prazo é configurável por conta, e dá para desligar em cada uma. É o que torna possível deixar seis, sete contas montadas num notebook de 8 GB.

          • atençãoNotificação que diz de onde veio

            A notificação nativa traz o nome da conta, o contador de não lidas aparece na barra lateral — e sobre o avatar quando ela está recolhida, a 72 pixels —, e o ícone da bandeja acumula o total. Clique na notificação e a janela foca aquela conta. Bandeja com badge incluso.

          • mexerReordenar, editar, hibernar por conta

            Arraste os itens da barra lateral para mudar a ordem (persistida entre sessões), botão direito abre o menu com editar/notificações/remover, e o modo recolhido guarda de uma inicialização para outra. Cada conta pode apontar para uma URL personalizada — serve qualquer webmail, painel ou chat interno.

          • telaCompartilhar tela funciona

            O seletor do WhatsApp Web pede permissão ao navegador e não aparece em Electron comum. Aqui a janela tem um seletor próprio, com miniaturas de telas e janelas, e devolve a escolha certa para a chamada de voz.

          • rascunhoAssistente que não envia por você

            Em conta WhatsApp, ele lê só o que está visível na tela, manda para o gateway que você configurar (Responses API ou Chat Completions) e devolve um rascunho no campo de edição. O envio continua sendo seu, sempre. A chave fica criptografada no safeStorage do sistema — nunca num arquivo nosso. Teams e os demais ainda não são suportados.

          • offlineInterface que não depende de CDN

            Bootstrap e ícones vêm empacotados dentro do app (src/vendor/). Sem internet a interface continua desenhando; o que não abre é o site do mensageiro, que também não abriria no navegador.

          • atualizarAvisos, sem instalar nada sozinho

            O app consulta a API de releases alguns segundos após abrir e só incomoda quando existe versão mais nova, oferecendo o download no navegador. Também dá para conferir em Ajuda → Verificar atualizações…. Nada é baixado nem instalado automaticamente.

          Mudanças no site
          A barra lateral e o contador de não lidas leem o DOM do mensageiro. Quando o WhatsApp Web muda a estrutura, esses contadores podem parar até o próximo ajuste — o envio de mensagens nunca dependeu disso e continua funcionando.
          acoplado ao HTML
          Tela branca ao trocar de conta
          Já aconteceu de verdade: uma refatoração removeu uma linha e a view de conta hibernada sumia ao voltar. Voltou no v1.6.0 e ganhou teste de regressão. Se você vir isso numa versão antiga, atualize.

          Três passos

          Instalação

          Instale por cima da versão anterior: contas, ordem da barra lateral e preferências são preservados.

          1. Windows — instalador NSIS

            Execute MultiChat-<versão>-setup.exe. Se o SmartScreen aparecer, Mais informações → Executar assim mesmo. O app abre já com uma conta WhatsApp.

          2. macOS — arm64 ou Intel

            Abra o .dmg (arm64 para Apple Silicon), arraste para Aplicativos e use botão direito → Abrir na primeira vez. Persistiu o aviso de app “danificado”? xattr -dr com.apple.quarantine /Applications/MultiChat.app

          3. Linux — x64

            chmod +x MultiChat-*.AppImage e execute o arquivo. Sem instalador, sem dependências extras.

          4. Abrir a primeira conta

            O ＋ no topo da barra lateral escolhe o serviço (WhatsApp, Teams, Telegram, Discord, Slack ou URL) e o nome da conta. Alternar é um clique no avatar, ou Ctrl+Tab.

          Rodar direto do código-fonte

          Node.js v24 é a versão testada (é a que roda no CI e na publicação de release). Dá para começar com v22.12 ou mais novo — o build-local.sh avisa, mas não bloqueia —, desde que o npm seja o que veio junto.

          git clone https://github.com/maiconfontana/multichat.git
cd multichat
npm install
npm run start

          O repositório traz npm test — são 32 testes unitários que cobrem a política de suspensão, o comparador de versões, o cliente do gateway e o adaptador do WhatsApp rodando num DOM falso — e npm run check para validar a sintaxe de todos os processos. Guia completo no README.

          Pular o SmartScreen e a quarentena

          Atualizar ou compilar na sua máquina

          Dois atalhos para quem não quer liberar app baixado manualmente — nenhum dos dois é obrigatório.

          Atualizar pelo terminal (Linux/macOS)

          Para quem instalou em ~/.local/bin/multichat: baixa a release, confere o SHA-256 contra o SHA256SUMS.txt publicado, troca o binário de forma atômica e guarda backup do anterior.

          ./update-local.sh              # atualiza
./update-local.sh --check      # só diz se há versão nova
./update-local.sh --rollback   # volta para o backup

          Compilar o binário localmente

          Um arquivo gerado na própria máquina não tem marca de origem de download, então não há SmartScreen nem quarentena para contornar. Custa ~1,3 GB de dependências e alguns minutos de build.

          ./build-local.sh               # Linux/macOS
.\build-local.ps1              # Windows
          Qual escolher? Na maioria dos casos o pacote pronto é mais simples e mais rápido. Compilar em casa é o substituto de assinar o aplicativo, não um teste de segurança: o projeto não é assinado, e compilar não torna o código mais confiável — só evita os avisos do sistema operacional.

          Como é feito

          Por dentro

          Os números desta seção foram lidos do repositório, e não do marketing dele.

          ARQUITETURA
          Electron — o app abre o site oficial de cada mensageiro numa WebContentsView separada. Não há protocolo próprio nem backend.
          ONDE VÃO OS DADOS
          Só na sua máquina — contas e preferências ficam no armazenamento local do Electron. O MultiChat não tem servidor para receber suas mensagens.
          O QUE SAI DA SUA REDE
          A API de releases do GitHub e, se você configurar e usar, o gateway de IA escolhido. A checagem de versão não envia identificadores.
          CÓDIGO E LICENÇA
          MIT — src/ tem ~2,9 mil linhas de JavaScript em 15 arquivos. Você pode ler, forkar e redistribuir.
          QUEM CONSTRÓI
          Manutenção de Maicon Fontana e contribuições de Natanael Walter, sobre a base de Diego Aguirre — autor da esmagadora maioria dos commits do upstream.
          COMO É PUBLICADO
          Uma tag v*.*.* dispara o build nas três plataformas no GitHub Actions, roda os mesmos testes do CI, gera os checksums e sobe a release.

          MultiChat é software livre sob licença MIT. Código em github.com/maiconfontana/multichat.

          Bugs e sugestões: abra uma issue. Vulnerabilidade: canal privado, não issue pública.

          Derivado de whatsapp-electron, de Diego Aguirre, que escreveu a base do app. Créditos mantidos.
