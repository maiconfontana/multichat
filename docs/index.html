        Recursos

        Sem roadmap como promessa: a lista abaixo é o que a versão atual entrega.

        1. Isolamento por conta

          Perfil de navegação próprio por conta: dois WhatsApp, duas contas do Teams, o que precisar — um login não derruba o outro.

        2. Memória sob controle

          Contas carregam sob demanda e suspendem após um tempo sem uso, devolvendo RAM sem perder o login. O prazo é configurável.

        3. Notificações e badges

          Notificação nativa com o nome da conta, contador de não lidas na barra lateral e na bandeja, e ícone de tray para não fechar sem querer.

        4. Compartilhamento de tela

          Seletor próprio de telas e janelas, funcional no WhatsApp Web.

        5. Assistente contextual

          Em contas do WhatsApp, gera um rascunho a partir das mensagens visíveis e insere no campo de edição — o envio continua sendo seu.

        6. Interface offline

          Estilos e ícones empacotados no app. A interface desenha sem depender de CDN.

        Rodar do código-fonte

        Requer Node.js v24.

        git clone https://github.com/maiconfontana/multichat.git
cd multichat
npm install
npm run start

        O repositório traz npm test (testes unitários), npm run check (validação de sintaxe) e scripts de build por plataforma — guia completo no README.

        Sem os avisos do sistema operacional

        Atualizar ou compilar localmente

        Dois caminhos para quem prefere pular SmartScreen e quarentena.

        Atualizar a instalação (Linux)

        Baixa a última release, confere o SHA-256 publicado e troca o binário de forma atômica, guardando backup:

        ./update-local.sh
./update-local.sh --check
./update-local.sh --rollback

        Compilar na sua máquina

        Gera um binário sem a marca de origem do download — abre sem SmartScreen (Windows) e sem quarentena (macOS). Custa ~1,3 GB de download:

        ./build-local.sh      # Linux/macOS
.\build-local.ps1     # Windows
        Qual escolher? Para a maioria dos casos, o pacote pronto é mais simples e mais rápido. Compilar localmente é a alternativa a assinar o aplicativo: num arquivo gerado na própria máquina não existe quarentena nem Mark-of-the-Web para bloquear. Não é um teste de segurança — o projeto não é assinado.
